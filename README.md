# Customer_Behaviour_Analysis
A Project done using python for EDA,SQL to answer business question and power bi for dashboard creation

## About the Project

Customer Behavior Analysis is a data analytics project designed to understand how customers interact with products and make purchasing decisions. The project uses customer shopping data to analyze purchasing habits, spending patterns, product preferences, customer demographics, and other factors that influence sales.

The analysis combines **Python, SQL, Excel, and Power BI** to transform raw customer data into meaningful insights and an interactive business dashboard.

## Problem Statement

Businesses collect large amounts of customer transaction data, but raw data alone does not provide useful business information. It is important to identify customer trends, understand purchasing behavior, recognize valuable customer segments, and determine which products and categories perform well.

This project addresses these problems by analyzing customer data and presenting the results in an easy-to-understand format.

## Project Objectives

* Understand overall customer purchasing behavior.
* Analyze customer spending patterns.
* Identify the most popular product categories.
* Compare purchasing behavior across different age groups.
* Analyze customer behavior based on gender and location.
* Identify seasonal purchasing trends.
* Analyze the impact of discounts and subscriptions.
* Understand customer payment preferences.
* Identify high-value customers.
* Create an interactive dashboard for business decision-making.
